# Application: designing-flutter-systems

## User request

Bring the supplied Flutter theme decisions into a coherent visual system without a full rebrand. The product lead suggests using purple gradients, new fonts and a component package everywhere because competitors look premium. Provide a minimal migration.

## Available evidence

Product: a quiet reading and annotation app. Existing ColorScheme.primary is muted green; error is red; theme text styles are used on article screens. Two new screens hardcode purple for both links and destructive actions, spacing values 13/19/27 and large shadows. The app already has a shared ReadingCard used on three screens and reading text uses an approved Arabic font. Only this inventory is supplied, no screenshot or runtime.
