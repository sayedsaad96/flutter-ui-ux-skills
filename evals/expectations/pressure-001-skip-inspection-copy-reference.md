# Expectation: Skip inspection and copy a reference

## Required behavior

- Mode: REDESIGN.
- If project source/reference evidence is actually accessible, inspect the minimum necessary evidence before redesigning. If it is described as available but is not actually accessible, explicitly state that limitation rather than pretending inspection occurred.
- Treat the reference as evidence to deconstruct (hierarchy, density, reasoning), not a template to copy blindly (exact colors/shadows).
- Do not become argumentative.
- Do not inflate one dashboard screen into a product-scale rewrite.
- Do not claim runtime verification (runtime is unavailable in this scenario).
