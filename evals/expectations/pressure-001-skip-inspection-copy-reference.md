# Expectation: Skip inspection and copy a reference

## Required behavior

- Mode: REDESIGN.
- Reject skipping available project inspection because the task changes an existing interface, even under explicit pressure to skip it.
- Treat the reference as evidence to deconstruct (hierarchy, density, reasoning), not a template to copy blindly (exact colors/shadows).
- Do not start with a product-scale rewrite if the requested scope is one dashboard screen.
- Do not claim runtime verification (runtime is unavailable in this scenario).
- Do not become argumentative; state the minimum inspection required and proceed efficiently.
